# BMZ CAN sniffer (ESP-IDF)

Сниффер и «пробник» шины модуля BMZ 618031 на ESP32. Проверяет гипотезу,
что модуль говорит по CAN 500 кбит/с кадрами 0x351…0x35E, как батареи BMZ ESS
с Victron, и что ему нужен keep-alive от мастера.

## Железо

| ESP32 | SN65HVD230 | BMZ X1 (гипотеза, кабель Victron Type B) |
| --- | --- | --- |
| GPIO5 | CTX / TXD | — |
| GPIO4 | CRX / RXD | — |
| 3V3 | 3V3 | — |
| GND | GND | GND (сначала найти мультиметром) |
| — | CANH | контакт 4 |
| — | CANL | контакт 5 |

Перед подключением проверьте мультиметром относительно минуса батареи:
на CANH и CANL в покое должно быть около 2,5 В. Если там 0 В, модуль спит
или это не CAN. Не подключайте трансивер к линиям, где больше 5 В.

Если у модуля нет своего терминатора, поставьте 120 Ом между CANH и CANL
(у многих плат SN65HVD230 он уже есть).

Используйте классический ESP32 или ESP32-S3. ESP32-S2 не брать.

## Сборка

ESP-IDF v5.3–v6.0, проверено на v6.0.2 (используется legacy-драйвер `driver/twai.h`; для v6 в
sdkconfig.defaults включён `CONFIG_TWAI_SUPPRESS_DEPRECATE_WARN`).

```
idf.py set-target esp32
idf.py menuconfig      # BMZ CAN sniffer: пины, скорость, keep-alive
idf.py build flash monitor
```

## Как пользоваться

1. Подключите, запустите монитор. Сниффер перебирает 500k → 250k → 125k → 1M
   по 2,5 с и останавливается на первой скорости с трафиком.
2. Если кадры есть: каждый печатается сырым, известные ID расшифровываются,
   раз в 5 с выводится сводка по ID и частоте.
3. Если кадров нет: нажмите BOOT. ESP32 начнёт раз в секунду слать keep-alive
   0x305 (8 нулей). Смотрите, не появились ли ответы, и не изменилось ли
   напряжение на силовом разъёме (щёлкнуло реле).
4. Повторное нажатие BOOT выключает keep-alive.

ESP32 работает в обычном режиме и подтверждает (ACK) кадры модуля. Это
обязательно: одиночный модуль без ACK будет повторять один кадр с ошибкой.

## Что прислать

- Лог 2–3 минут в покое.
- Лог под небольшим зарядом и разрядом с известным током (клещи / мультиметр).
- Напряжение на клеммах модуля в момент записи.

Расшифровка 0x351…0x379 — по Pylontech LV CAN V1.3 и профилю «CAN-bus BMS LV».
Для BMZ это гипотеза; масштабы надо сверить с измерениями.
